# TEAM-V — Why Dhaka Keeps Growing & The Case for a Decentralized Bangladesh

An interactive scrollytelling presentation and data story explaining the imperative for a decentralized Bangladesh — analyzing urban migration drivers, centralization feedback loops, regional potential, and strategic policy solutions.

---

## 🚀 Key Highlights

- **Interactive Scrollytelling**: Engaging visual narrative with dynamic data displays.
- **Data-Driven Insights**: Regional analytics, economic metrics, and demographic trends.
- **Strategic Vision**: Actionable decentralization roadmap and policy framework.

---

## 🛠️ Setup & Running

### Prerequisites
- **Node.js** (v18+ recommended)

### Instructions

1. **Install dependencies:**
   ```bash
   npm install
   ```

2. **Start the development server:**
   ```bash
   npm run dev
   ```
   *Access the presentation at `http://localhost:3000` or on your local network.*
